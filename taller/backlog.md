# Backlog de Historias de Usuario

## Historias por pantalla

### Inicio
- Como usuario anónimo, quiero ver una página de bienvenida, para entender qué ofrece el sistema.

### Reportar
- Como miembro de la comunidad, quiero enviar una denuncia anónima de bullying, para que el equipo la reciba sin miedo.

### Login
- Como usuario, quiero iniciar sesión con mi correo y contraseña, para acceder al panel de administración.
- Como nuevo usuario, quiero registrarme, para usar el sistema en el futuro.

### Panel admin
- Como administrador, quiero ver todas las denuncias, para revisarlas y priorizarlas.
- Como administrador, quiero asignar denuncias a docentes, para que cada caso tenga seguimiento.
- Como administrador, quiero cambiar el estado de una denuncia, para indicar si está en revisión o resuelta.
- Como administrador, quiero ver estadísticas de denuncias, para entender la gravedad del problema.
