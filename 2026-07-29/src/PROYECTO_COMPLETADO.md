## 🆘 Si Algo No Funciona

| Problema | Solución |
|----------|----------|
| Menú no aparece | Verifica importaciones en App.jsx |
| Estilos no aplican | Asegúrate de importar .css files |
| Menú se ve igual | Reemplazaste correctamente `<Menu>` por `<MenuAdvanced>`? |
| Página en construcción no se ve | Verifica que `EnConstruccion.css` esté importado |
| Logout no funciona | Verifica que `handleSignOut` esté correctamente implementado |
| Rol admin no se detecta | Usuario debe tener correo @admin.com o rol en BD |
